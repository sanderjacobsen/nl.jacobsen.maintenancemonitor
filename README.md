# Maintenance Monitor / Huisarts (Homey app)

Houd al het onderhoud in en om je huis bij: rookmelders, airco, wasmachine, CV-ketel, 3D-printer, dakgoot …
Per onderdeel (een apparaat in Homey) één of meer taken met een eigen termijn; Huisarts meldt wanneer iets nodig is.

- Onderdeel toevoegen: Apparaat toevoegen > Huisarts (kies een soort, vink voorbeeldtaken aan, vul 'laatst gedaan' in).
- Taken beheren, afvinken en uitstellen: Instellingen > Apps > Huisarts > Configureren.
- Meldingen: Homey-tijdlijn (push aanzetten via Homey > Instellingen > Meldingen > Huisarts) en flowkaarten.

Ontwerp en fasering: zie ONTWERP.md. Tests van de datumlogica: `npm test`.
